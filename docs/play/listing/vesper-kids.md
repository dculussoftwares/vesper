# Vesper Kids: store listing

**Title (max 30):** Vesper Kids

**Short description (max 80):**
Companion app for parents: manage app limits on your child's phone, openly.

**Full description (max 4000):**

Vesper Kids is the child-phone companion to Vesper. It is for parents and guardians who want to manage
how their child uses their own phone, and it works openly: the child can see that it is installed and that the phone
is managed.

You need the Vesper app on your own phone. Install Vesper Kids on your child's phone, open it, and scan the
QR code it shows with Vesper. Both phones show a matching 6-digit code, and the child's phone asks for
approval before it is linked. Nothing is monitored until that approval.

What the parent can do from their phone:
- Set time limits, use-then-lock cycles and blocked hours.
- Block an app right away, lock every app except the always-allowed ones, or start a focus session.
- See screen time, which apps were used and how often, and which app is open now.
- See the child's installed apps, battery level, Android version and whether the phone is online.
- Approve or decline a request for more time.
- Get an alert if a permission Vesper Kids needs is turned off, and send a reminder to turn it back on.

What the child sees:
- A persistent notification while the phone is managed, with the parent's name.
- A home screen listing the rules the parent has set and today's screen time.
- A button on the block screen to ask the parent for more time.
- An "Unlink" button. The child can unlink at any time while online, and the parent is notified.

This app is not designed to be hidden and is not for monitoring another adult. Using it on someone's phone without
their knowledge is not allowed.

Permissions, and why:
- Usage access: to measure time spent in each app, shown to the parent.
- Accessibility service: to see which app is open, so a blocked app can be covered and the parent can see screen time.
  It does not read messages, passwords, typing or anything else on the screen.
- Display over other apps: to show the block screen.
- Notifications: to show the "managed" notice and reminders.

Data: the information above is sent only to the linked parent's account, through Google Firebase. No ads, no analytics,
no advertising ID, and nothing is sold or shared with third parties. Unlinking deletes this phone's data, and the parent
can also delete their whole account. Privacy policy: https://vesper.dculus.com/privacy
